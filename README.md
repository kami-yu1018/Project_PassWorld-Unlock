# Project_PassWorld-Unlock

各シーンに実装するもの

Scene_title：タイトル画面
・タイトル画面（画面の背景、タイトルテキスト、スタートテキストofボタン）

Scene_level：難易度選択画面
・画面（背景、難易度テキスト（easy,nomal,hard）、出てくる敵のビジュアルと説明）
・難易度を選択したらその難易度の敵をバトル画面で生成するようにする

Scene_setting：パーティー編成画面
・画面（背景、パーティーメンバーのビジュアル、名前、役職アイコン、スタートテキスト）
・パーティーメンバーが確定したらそのメンバーをバトル画面で生成するようにする

Scene_play：バトル画面
・画面（背景、敵キャラ、味方、バトルUI、HP,MP,APPの描画）
・最初に敵キャラと味方キャラのスピードを比較し、攻撃順を決定する
・味方キャラの攻撃はそれぞれの順番にスキルを選択してパスワードを入力、攻撃する
・敵キャラの攻撃はランダムな味方を選択し、ターンで異なる攻撃を行う
・ターンをカウントする

Scene_end：終了画面
・画面（背景、ThankYouForPlayingのテキスト）

ほかに必要なもの
・パスワード入力のプログラム（スキルごとにパスワードを設定、パスワードと入力内容の正誤判定、成功で攻撃、失敗で攻撃失敗）
・敵キャラの攻撃プログラム（ランダムな味方のターゲティング、攻撃内容と順番）
・ダメージ計算プログラム（攻撃力、防御力、スキル効果、バフ、デバフ効果でダメージを計算する）

やること
・戦闘画面、戦闘プログラムを実装
・スキルデータの設定（最初は一つだけでいい）
・戦闘画面にて、テキストボックスを追加、今のところ画像内なしでテキストログで戦闘内容を説明するように実装
・入力テキストと設定したテキストとの正誤判定
・エンターを押したら次の画面へ映るようにする（play→end除く）
